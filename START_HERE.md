# PARTI DA QUI

Per il test gratuito apri questa repo su GitHub e scegli **Code → Codespaces → Create codespace on main**. Attendi la preparazione automatica, quindi nel terminale esegui:

```bash
./scripts/codespaces-run.sh
```

Inserisci una password temporanea (minimo 10 caratteri) e, se vuoi testare gli upload, token Gofile e/o API key Pixeldrain. Non salvare questi segreti nella repository.

Poi apri **PORTS → 8080 → Open in Browser** e lascia la porta **Private**. Accedi alla dashboard, aggiungi una sorgente autorizzata e lascia il terminale aperto. Il preset test usa segmenti da 10 minuti.

Per fermare: `CTRL+C`, poi **Stop codespace** per non consumare quota.
